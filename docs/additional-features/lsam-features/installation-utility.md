# Installation Utility

## What is it?

The SMA/INSTALL program automates most of the steps required for an MCP Agent installation or upgrade and is the preferred alternative to performing a manual installation. Full procedures for using SMA/INSTALL are documented in the Automated Installation/Upgrade topic.

- Automate the installation of the MCP Agent to reduce manual configuration steps and the risk of errors.
- Perform an automated upgrade of an existing MCP Agent installation.

For full procedures, refer to [Automated Installation/Upgrade](../../installation/automated-installation-upgrade).
