# Data Collector for MCP (SMASUP)

## What is it?

The Data Collector utility collects debug information on an MCP machine to support problem analysis. After collection, the output container files must be transferred to a Windows machine, zipped, and uploaded to SMA Technologies' FTP site for further analysis.

- Collect diagnostic data from an MCP system when troubleshooting an issue with SMA Technologies support.
- Generate container files that can be submitted alongside a Salesforce support case for investigation.

Following data collection, FTP the container files (three output files) to a Windows machine. Then zip these files and place them in your directory on SMA Technologies' FTP site. Note in the Salesforce case comment that the files have been uploaded and are available for further analysis. For more information, refer to [Problem Resolution and Debugging](../../debugging).
