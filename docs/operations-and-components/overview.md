# Operations and Components Overview

## What is it?

The Operations and Components section covers day-to-day operation of the MCP Agent and the tools used to manage it at runtime. This includes starting and stopping the agent, using the SMA/MANAGER utility to inspect and adjust settings without a restart, and a reference for all programs and files installed with the agent.

- Use SMA/MANAGER to manage the running agent — checking status, reloading definitions files, viewing the display message backlog, and accessing debugging options — without stopping the agent.
- Use the programs and files reference pages to understand what each installed component does and which files are created or modified by the agent.
