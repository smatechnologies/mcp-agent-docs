# Reference Information Overview

## What is it?

The Reference Information section provides look-up resources for diagnosing problems and understanding MCP Agent messages. It includes message code tables for machine communication, file monitoring, and file transfer; a known issues list; troubleshooting tables organized by symptom category; and archived legacy configuration documentation for sites upgrading from older agent versions.

- Use the message tables and troubleshooting guides to identify and resolve issues with the MCP Agent.
- Use the legacy documentation when upgrading from an older version to understand configuration parameter changes.
